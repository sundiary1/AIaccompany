# Starter Jelly Island — procedural art brief

No downloaded models, image textures or third-party asset references are used.

- Soft squircle silhouette, cushion-like grass lip and rounded underside.
- Sage/lime greens, biscuit and chestnut soil, cream daisies and quiet grey pebbles.
- Two simple faceted trees concentrated at the back, a generous clear foreground.
- Warm cream studio, orthographic three-quarter view, soft detached ground shadow.
- Blender uses metres and Z-up. GLB uses the standard glTF Y-up convention.

The model is static. `Starter_Jelly_Island` is the future whole-island animation pivot;
`Future_Placement` is an invisible anchor for a reserved 3.6 × 3.5 m area.
